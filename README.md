# Калькулятор числовых выражений

Проект позволяет вычислять простые числовые выражения, вводимые пользователем. На данный момент программа поддерживает:
- Математические бинарные операторы (+, -, *, /)
- Приоритетность операций задаётся круглыми скобками
- Дробная часть в десятичных дробях отделяется точкой или запятой
- Также программа выводит запись выражения в обратной польской записи (нотации).

## Technology stack:

- С#
- Avalonia UI (MVVM pattern)
